# Familiar DB

Roster database for Familiar: every character, their types, their evolutions, and who the villains are.

## Editing

Double-click `start.bat` (or run `py serve.py` and open http://localhost:8000).

- Click a picture slot, then press Ctrl+V to paste a picture. Dragging a picture file onto the slot works too.
- Click a character to edit its name, anime, villain or gag tag, its forms and their types.
- Changes save to `data/characters.json` and pictures to `images/`. Commit and push them to publish.

The hosted copy of the site is read-only.
